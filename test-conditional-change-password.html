Conditional Change Password Demo

This demonstrates how the "Change Password" menu item appears/disappears based on login method.

Google Login User

Logged in with Google
Sidenav Menu
My Profile My Properties My Favorites Add Property Change Password (Hidden) Logout
Note: Change Password is hidden because Google manages the user's password.

Email/Password Login User

Logged in with Email/Password
Sidenav Menu
My Profile My Properties My Favorites Add Property Change Password (Visible) Logout
Note: Change Password is visible because the user can change their email/password credentials.

Implementation Details:

Login Method Tracking
  • Session Service: Stores login method ('email' or 'google') in localStorage
  • Login Component: Sets method to 'google' for Google login
  • Register Component: Sets method to 'google' for Google registration
  • OTP Verification: Sets method to 'email' for email registration completion
  • Regular Login: Sets method to 'email' for email/password login
Sidenav Logic
// In sidenav.ts
checkLoginMethod(): void {
  const loginMethod = this.session.getLoginMethod();
  this.showChangePassword = loginMethod === 'email';
}

// In sidenav.html
@if (showChangePassword) {
  <a class="nav-item password-icon" routerLink="/user-dashboard/change-password">
    <i class="bi bi-key"></i>
    <span>Change Password</span>
  </a>
}
Session Storage Structure
{
  "token": "jwt_token_here",
  "loginMethod": "email" | "google"
