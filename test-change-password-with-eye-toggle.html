Change Password

Eye Toggle Features:

  • Default State: All password fields show bi-eye-slash icon (password hidden)
  • Toggle Functionality: Click eye icon to show/hide password
  • Icon States:
    • bi-eye-slash - Password hidden (default)
    • bi-eye - Password visible
  • Accessibility: Proper ARIA labels for screen readers
  • Styling: Consistent with Bootstrap input groups
  • All Fields: Current Password, New Password, and Confirm Password all have eye toggle
