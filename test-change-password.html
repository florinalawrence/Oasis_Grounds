Change Password

Change Password Form Features:

  • Card Layout: Same structure as profile card with header and body
  • Form Fields:
    • Current Password - Required, minimum 6 characters
    • New Password - Required, minimum 6 characters
    • Confirm Password - Required, must match new password
  • Save Button: Same styling as profile save button with gradient background
  • Validation: Form validation with error messages
  • Loading State: Button shows spinner when submitting
  • Responsive: Works on mobile and desktop
